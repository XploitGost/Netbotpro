# NetBotPro

[English](README.md) | [نصب](docs/INSTALL.md) | [معماری](docs/ARCHITECTURE.md) | [امنیت](SECURITY.md)

NetBotPro ابزار محلی پایش شبکه، بررسی متادیتای بسته‌ها، تحلیل جریان‌ها و
پیگیری رخدادهای امنیتی است. backend با Python و FastAPI، رابط با React و
پوستهٔ دسکتاپ با Electron ساخته شده است. کپچر ویندوز به Npcap نیاز دارد.

## وضعیت واقعی پروژه

شاخهٔ `main` مسیر توسعهٔ نسخهٔ 0.2.0 است، نه اعلام انتشار یک نسخهٔ عملیاتی
جدید. فایل‌های نسخه‌های قدیمی الزاماً اصلاحات جدید را ندارند. عبور از تست‌ها
به معنی تضمین نبود افت بسته، نبود خطای تشخیص یا پایداری نامحدود نیست.

رابط Command Center، Live Monitor، Investigate و Fleet اکنون در
`frontend/src/desktop` قرار دارد و با ورودی آزمایشی `desktop.html` از سورس
ساخته می‌شود. کنترلر و API آن با رابط استاندارد مشترک است و وابستگی ساخت به
پچ bundle قدیمی حذف شده است. نسخهٔ نصب‌شده تغییر نکرده؛ تطبیق کامل امکانات
و تست طولانی با ترافیک واقعی پیش از جایگزینی نسخهٔ نصب‌شده لازم است.

## قابلیت‌ها

- مشاهدهٔ بسته‌ها، هشدارها، فیلتر، صفحه‌بندی و بررسی بستهٔ انتخاب‌شده.
- تحلیل جریان و گفتگو، جزئیات پروتکل و توضیح شواهد ریسک.
- نمایش دامنه با شواهد DNS، TLS SNI یا HTTP Host، در صورت قابل‌مشاهده بودن.
- فشرده‌سازی بدون حذف جزئیات جریان‌های غیرفعال و صف‌های محدود در مراحل مختلف.
- بازیابی کپچر هنگام تغییر رابط و مسیر، با محدودیت‌های وابسته به سیستم و درایور.
- Fleet برای خلاصهٔ وضعیت عامل‌های ثبت‌شده و سنسور محلی؛ نه کنترل از راه دور.
- تحلیل PCAP مجاز، گزارش و خروجی پالایش‌شده.

نام دامنه همیشه قابل‌استخراج نیست؛ IP مشترک CDN یا ترافیک رمزگذاری‌شده را
نباید به یک سایت قطعی نسبت داد. برنامه HTTPS را رمزگشایی نمی‌کند و تاریخچهٔ
مرورگر، رمز، کوکی یا عبارت جست‌وجوی رمزگذاری‌شده را استخراج نمی‌کند.
از کپچر لپ‌تاپ هم نمی‌توان مسیر خروجی روتر و IP عمومی هر اتصال را قطعی دانست.

## مسیر بعدی

یکپارچه‌کردن مسیر سورس و ساخت، جداسازی کپچر از تحلیل و ذخیره‌سازی، قرارداد
دقیق تحویل و تأیید داده، محدودسازی وضعیت بلندمدت و تست پایداری پیوسته.
استفاده از Rust فقط برای بخش‌هایی بررسی می‌شود که profiling نیازشان را ثابت
کند؛ در وضعیت فعلی بخش Rust پیاده‌سازی نشده است.

[نقشهٔ راه](docs/ROADMAP.md) و [معیارهای اعتبارسنجی](docs/VALIDATION.md)
وضعیت و محدودیت‌ها را توضیح می‌دهند.

برای اجرا، راهنمای نصب را دنبال کن. برای گزارش خطای عادی از Issue با اطلاعات
پالایش‌شده استفاده کن؛ آسیب‌پذیری امنیتی را از مسیر خصوصی در SECURITY.md
گزارش بده. رمز، توکن، فایل خام ترافیک یا اسکرین‌شات حاوی اطلاعات شخصی منتشر نکن.

مجوز پروژه MIT است. فقط روی سیستم‌ها و شبکه‌هایی که مجوزشان را داری استفاده کن.
